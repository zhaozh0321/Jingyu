# 数据与隐私

鲸语是使用个人 API Key 的第三方客户端。应用没有内置共享密钥。

| 数据 | 保存与使用 |
| --- | --- |
| API Key | 用 Android Keystore 保护的 AES-GCM 数据保存在本机；请求模型或账户接口时作为凭据使用 |
| 对话历史 | 应用私有目录中的 JSON；不应描述为端到端加密 |
| 长期记忆 | 本机加密存储；相关记忆可能按需加入模型请求 |
| 附件和消息 | 用户发送时可能作为模型上下文传到服务商；附件阅读不代表内容永不离机 |
| 生成文件 | 本机文件；打开、保存和分享由用户发起 |
| 备份 | 用户主动导出的 JSON 是明文，应自行妥善保管 |

联网搜索与抓取会把相应检索词或 URL 发送到服务端工具接口。服务端的保存、计费和数据处理规则以对应服务商条款为准。

不要把 API Key、备份、真实对话或个人截图提交到 GitHub Issue。卸载可能导致本地数据及加密材料丢失；发布升级必须保留应用 ID 和签名。

本说明描述当前代码的数据流，不是服务商的隐私保证。加入遥测或新数据目的地前，必须同步代码、界面说明和本文件。
